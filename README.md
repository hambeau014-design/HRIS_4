## 관리자/사원 구분
사이드바에서 선택 메뉴를 다르게 배치함으로써 차이 지정
다른 메뉴도 막혀있긴 하나 추후 수정할 예정

--------임시데이터------------

관리자 계정
id : admin
passwd : 12345

사원 계정
id : user
passwd : 12345


## src/api 폴더

각 사이드바 메뉴에 따른 api를 설계했습니다(잘 설계된거지 모르겠네요)

평가관리 부분이랑 문서 결재 부분이 약간 비뚤게 출력됩니다.흠.제가 시간이 된다면 최대한 수정해보겠습니다.
